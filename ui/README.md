# Wiki workspace

Весь UI находится в этом каталоге. Go отдаёт встроенную React-статику и проксирует
`/api/v1/*` в wikisvc, `/agent-api/*` в wikiagent. Модель вызывается агентом.
UI не открывает рабочую папку вики, SQLite или конфигурацию модели.

## Сборка и запуск

Из корня backend:

```sh
nix build .#ui
./result/bin/wiki-ui
# http://127.0.0.1:8789
```

Для AlmaLinux используйте `nix build .#deployment` и
[инструкцию установки](../docs/deploy-almalinux.md). В bundle входит
`wiki-ui.service` с отдельным пользователем llm-ui.

| Переменная | По умолчанию |
|---|---|
| WIKI_UI_BIND | 127.0.0.1:8789 |
| WIKI_UI_WIKISVC_URL | http://127.0.0.1:8787 |
| WIKI_UI_AGENT_URL | http://127.0.0.1:8788 |

Для входа нужен личный токен wikisvc. Редактирование создаёт предложение;
принятие требует другого человека с ролью reviewer/admin. В истории чата видны
только свои сессии. Чат требует допуска не ниже допуска рабочего токена агента.
`reader` может читать разрешённые страницы, граф и инструкции. Сырьё требует
`restricted`. Все проверки повторяются в API независимо от кнопок UI.

## Разработка

```sh
# Из корня backend, wikisvc и wikiagent запущены отдельно:
nix develop
cd ui
npm ci
npm run dev
# http://127.0.0.1:5173, API проксируются на 8787/8788.
```

Сборка без Nix требует Node.js 22.12+ и Go 1.24+:

```sh
npm ci
npm run build
CGO_ENABLED=0 go build -trimpath -o wiki-ui .
./wiki-ui
```

Для запуска готового бинарника не нужны npm, Node.js, Go или каталог dist.
Зависимости фронтенда зафиксированы в package-lock.json; Nix дополнительно
проверяет их хеш в package.nix. После обновления lock обновите npmDepsHash по
хешу, который выдаст `nix build .#ui` при значении `pkgs.lib.fakeHash`.

## Проверки

```sh
# В nix develop, из ui/:
npm ci
npm run build
npm run format:check
CGO_ENABLED=0 go test ./...
npm exec playwright install chromium
npm test
# Либо установленный Chrome, без скачивания Playwright Chromium:
CHROME_BIN="$(command -v google-chrome)" npm test
```

Браузерные тесты запускают настоящие wikisvc/wikiagent, Go-прокси и собранный
интерфейс на 18787/18788/18789. Только модель заменена детерминированным ответчиком;
это проверка интеграции UI, не качества LLM. Данные создаются во временной папке,
рабочая вики и её токены не используются. Тестовый конфиг находится в игнорируемой
`.e2e/` с правами 0600 и удаляется при остановке. Скриншоты остаются в `.e2e/`.
Запускайте тесты из nix develop либо из Python venv с зависимостями backend.[dev].

Проверяются вход/выход, поиск, тема, редактор, запрет собственного ревью,
принятие другим человеком, безопасный Markdown, потоковый чат и изоляция истории,
загрузка/извлечение источника, экспорт, граф, права читателя и мобильные экраны.
Go-тесты отдельно проверяют маршрутизацию и передачу токена, отказ до чтения тела,
защитные заголовки, отсутствие кэширования API и немедленную доставку SSE.

## Поведение

Шрифты хранятся локально. Токен — в памяти и sessionStorage, тема — в localStorage.
Выход очищает токен и Query cache. Markdown не исполняет HTML; внешние изображения
не загружаются. UI использует CSP, не хранит серверных токенов и не ставит cookies.
Остановка получения ответа закрывает поток в браузере; уже запущенная операция
агента может завершиться, её результат доступен после обновления диалога.

Граф показывает до 350 узлов одновременно; для большой вики используйте фокус
страницы. Списки загружают все разрешённые страницы порциями по 100 записей.
Права, ошибки API, отсутствие данных и недоступность агента отображаются отдельно.
