# Новое приложение
1. Выбери профиль через profiles, вызови get_policies(profile) до написания кода.
2. При первом применении правила, сомнении или подготовке примера прочитай get_rule(id), включая уточнения и конфликты.
3. Найди автоматизируемый процесс, системы и данные через search/get_context. Не выдумывай недостающие факты.
4. Создай предложение с app и связями automates, integrates_with, reads, writes. governed_by необязательна: доставка правил определяется scopes.
5. Реализуй приложение по тезисам; учитывай enforced_by и запускай соответствующие проверки.
6. Обнови архитектуру, ADR и уроки через предложение, выполни validate_proposal и submit_proposal. Принимает человек.
