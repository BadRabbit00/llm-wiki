# Карта реализации и документации

Текущее назначение системы — в [SPEC.md](../../SPEC.md). Этот файл заменяет
хронологический журнал этапов; прежние протоколы сохраняются в истории Git.
Правила работы с кодом — в [AGENTS.md](../AGENTS.md), решения по неоднозначностям —
в [decisions.md](decisions.md).

## Компоненты

| Компонент | Код | Назначение |
|---|---|---|
| Ядро wikisvc | `src/wikisvc/` | Детерминированные правила, поиск, компиляция политик, предложения и решения человека |
| Агент wikiagent | `src/wikiagent/` | Модель, книги, чат, самолечение и сверка проектной документации |
| HTTP API | `src/wikisvc/api/` | Авторизация и доступ к операциям ядра |
| MCP | `src/wikisvc/mcp_server.py`, `tool_contracts.py` | Общие контракты инструментов для stdio/HTTP и модели |
| UI | `ui/` | Вход OIDC, предложения, ревью, находки и задачи агента |
| Развёртывание | `deploy/` | Единый узел, конфигурация сервисов, резервное копирование и восстановление |
| Проектный CLI | [wk](../../wk/README.md) | Инициализация, документация, политики, встроенные навыки и хуки |
| Репозиторий контента | `$WIKI_ROOT` | Правила, источники, схемы, профили и шаблоны проектов в Git. Отдельный репозиторий, локально не хранится |

`mainserver/` — отдельный репозиторий установки Arch, вне состава llm-wiki.
Данные состояния, индексы и рабочие каталоги развёртывания не заменяют
версионируемый репозиторий контента.

## Проверка изменений

Из корня backend:

```sh
nix develop -c just lint
nix develop -c pytest --cov --cov-report=term-missing
nix flake check
```

Lint включает Ruff и mypy strict. Pytest проверяет заданные в pyproject.toml
модули с порогом покрытия 85%; Nix проверяет также UI и deployment.
Правки CLI проверяются отдельно в `../wk` по его README.

## Архив требований

[ТЗ v1](wiki-service-spec-v1.md) и [ТЗ v2](policy-layer-spec.md) сохранены на прежних
путях как архив, чтобы не потерять ссылки на разделы и причины принятых решений.
Для новой работы используются SPEC.md, decisions.md и действующие AGENTS.md.
История изменений и прежний журнал этапов доступны через
`git log -- docs/progress.md`.
