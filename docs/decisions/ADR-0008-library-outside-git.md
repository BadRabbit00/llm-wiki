# ADR-0008 — Библиотека книг вне git
status: accepted | date: 2026-10-02

## Контекст

Правила извлекаются из книг и статей. Это чужие файлы на десятки мегабайт.

## Решение

Категория `library` в загрузке сырья сохраняет файл в `$STATE_DIR/library/<год>/<sha8>-<имя>`
(BKT-wikisvc-core.library) и не коммитит. Извлечённый текст — кэш `$STATE_DIR/extract/<sha256>/`
(BKT-wikisvc-core.extract). В вике остаётся страница `source` с библиографией, хешем и выжимкой.

## Почему

- лицензия: полный текст чужой книги не попадает в репозиторий контента;
- размер: git не раздувается навсегда.

## Что рассматривали и отвергли

| вариант | почему нет |
|---|---|
| хранить книги в `raw/` git-репозитория | лицензия и размер репозитория |

## Последствия

- `STATE_DIR` содержит данные, которые нужны в бэкапе (RES-state-db);
- лимит загрузки отдельный — `MAX_LIBRARY_UPLOAD_MB` (по умолчанию 200);
- затрагивает: LIB-wikisvc-core, RES-state-db, SVC-wikiagent.
