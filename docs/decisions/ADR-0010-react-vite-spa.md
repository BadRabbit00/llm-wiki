# ADR-0010 — React и Vite для веб-интерфейса
status: accepted | date: 2026-10-07

## Контекст

Нужен рабочий интерфейс: редактирование и ревью предложений, потоковый чат, источники, задачи, граф,
экспорт политик (коммит `1270d9e`).

## Решение

SPA на LANG-typescript с DEP-npm-react, роутингом DEP-npm-react-router-dom и данными через
DEP-npm-tanstack-react-query; сборка TOOL-vite. Собранные файлы встраиваются в Go-бинарник SVC-wiki-ui
(ADR-0009), отдельного сервера для фронтенда нет.

## Почему

- статическая сборка встраивается в один бинарник и отдаётся с того же origin, что и API;
- версии закреплены `ui/package-lock.json`, сборка воспроизводится Nix (`ui/package.nix`).

Почему выбран именно React, в источниках не записано.

## Что рассматривали и отвергли

В источниках альтернативы не записаны.

## Последствия

- CI проверяет Prettier и `tsc`, браузерные сценарии — Playwright на PR в `main` (PIPE-ci);
- затрагивает: SVC-wiki-ui, LANG-typescript, DEP-npm-react, TOOL-vite, TOOL-npm.
