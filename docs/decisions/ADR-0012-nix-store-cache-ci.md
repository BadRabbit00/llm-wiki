# ADR-0012 — Кэш Nix store в CI
status: accepted | date: 2026-10-12

## Контекст

Проект закреплён на Python 3.12, а в закреплённом nixpkgs по умолчанию Python 3.14, поэтому пакетов
python3.12 нет в cache.nixos.org. Каждый джоб собирал их из исходников с их тестами: долго, а тесты
на тайминги (`tenacity`) падали на общих раннерах.

## Решение

`nix-community/cache-nix-action` сохраняет `/nix` под ключом из хеша `flake.lock`, `flake.nix`,
`ui/package.nix` и `deploy/*.nix`, отдельно для каждого джоба; без своего кэша джоб берёт любой
с префиксом `nix-Linux-`. Кэш PIPE-release сохраняется на `main` и виден всем веткам и PR.

## Почему

- сторонние пакеты собираются один раз;
- purge не включён, чтобы CI не требовалось право `actions: write`; старые записи вытесняет GitHub (LRU, 10 GB).

## Что рассматривали и отвергли

| вариант | почему нет |
|---|---|
| собирать всё на каждом джобе | долго и нестабильно из-за чужих тестов |

## Последствия

- кэш может быть вытеснен, тогда джоб снова собирает всё;
- затрагивает: PIPE-ci, PIPE-release, TOOL-nix, TOOL-github-actions.
