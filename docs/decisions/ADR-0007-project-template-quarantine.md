# ADR-0007 — Карантин некорректных шаблонов проектов
status: accepted | date: 2026-10-09

## Контекст

Шаблоны проектов необязательны. Сломанный шаблон (например, ссылка на удалённый профиль или scope)
раньше не давал стартовать API, MCP и выдаче политик.

## Решение

Некорректный шаблон исключается из доступных с фиксированной причиной в `Registry.invalid_project_templates`
(ключ — имя файла). Запрос такого шаблона — ERR-template_invalid (422), отсутствие файла — ERR-template_unknown (404).
Каждому шаблону в карантине соответствуют WARNING при загрузке и ошибка в lint. Остальная схема
по-прежнему падает при ошибке.

## Почему

- необязательная часть не должна блокировать обязательные;
- причина без исходного YAML и деталей валидации не раскрывает содержимое.

## Что рассматривали и отвергли

| вариант | почему нет |
|---|---|
| отказ старта при любом сломанном шаблоне | вика недоступна из-за второстепенного файла |
| молча пропускать шаблон | ошибку никто не заметит |

## Последствия

- сломанный шаблон виден в lint и логе, а не в простое службы;
- затрагивает: LIB-wikisvc-core, SVC-wikisvc, FMT-wikisvc-core.project-template.
