# wikiagent: устройство кода

> Модули верхнего уровня и ключевые классы. Не каждый класс — только те, что видны снаружи
> модуля, и те, где живёт важная логика.

## Модули

```mermaid
flowchart TD
  cli["MOD-wikiagent.cli"] --> api["MOD-wikiagent.api"]
  api --> chat["MOD-wikiagent.chat"]
  api --> jobs["MOD-wikiagent.jobs"]
  jobs --> heal["MOD-wikiagent.heal"]
  jobs --> chat
  heal --> chat
  chat --> planner["MOD-wikiagent.planner"]
  chat --> tools["MOD-wikiagent.tools"]
  planner --> models["MOD-wikiagent.models"]
  jobs --> models
  heal --> models
  models --> prompts["MOD-wikiagent.prompts"]
  models --> state["MOD-wikiagent.state"]
  planner --> client["MOD-wikiagent.client"]
  tools --> client
  jobs --> state
  chat --> state
  api --> config["MOD-wikiagent.config"]
  client --> core["LIB-wikisvc-core"]
  jobs -. "v3 draft" .-> ingest["MOD-wikiagent.ingest"]
  ingest -.-> judge["MOD-wikiagent.judge"]
  heal -.-> judge
  jobs -.-> judge
  ingest -.-> models
  ingest -.-> client
  judge -.-> models
  judge -.-> state
```

Из LIB-wikisvc-core агент импортирует только перечисленное в `component.md` (ошибки, домен
markdown/patch/secrets/validate, `tool_contracts`, `db_version`, `state_db.now`); данные вики — только
через `CLS-wikiagent.WikiClient`. Обратное направление запрещено и проверено тестом
`tests/test_security_invariants.py::test_wikisvc_has_no_network_or_agent_imports` (INV-core-deterministic).
