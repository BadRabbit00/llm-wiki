2026-10-06, локальный файл `gemma-4-12b-it-uncensored-Q4_K_M.gguf` из
`~/.eva/models/gemma-4-12b-it-uncensored-GGUF/`. Все роли: `wiki-gemma-12b`.
llama-server b10809-5266f24, одна сессия, context 16384, temperature 0,
JSON schema, reasoning off, GPU layers 35, KV q8_0. RTX 5060 Laptop 8 ГиБ.
Команда запуска приведена в README; сценарии не содержат данных рабочей вики.

| Промпт | Совпадение действий и вопросов | Запретные вызовы | Лишние вопросы в среднем |
|---|---:|---:|---:|
| v2.1, схема только в response_format | 1/12 (8,33%) | 0 | 1,08 |
| v2.2, схема в контексте и явные defaults | 10/12 (83,33%) | 0 | 0,083 |

Отчёты: [v2.1](evals/gemma-12b-v2.1.json), [v2.2](evals/gemma-12b-v2.2.json),
[v2.3](evals/gemma-12b-v2.3.json). В окончательном прогоне v2.3 не прошли: новое правило с «только» ошибочно повышено моделью до must
(лишний вопрос о владельце); связи с pattern не прошли проверку структурного
ответа после трёх попыток. В остальных случаях прошли дубликат, уточнение,
расширение области, конфликты should/must, неоднозначная область, пачка правил,
бизнес-факт, ответ на прежний вопрос и отмена.

**Модель не достигла порога для рабочего planner/chat:** спецификация требует
≥90% на минимум 30 сценариях, здесь 83,33% на 12. Production_ready=false.
Настройка модели остаётся заменяемой. Эти же 12 сценариев на scripted-модели
проверяют конвейер со 100% совпадением; это отдельная проверка, не оценка LLM.

Воспроизведение:

```sh
wikiagent eval --role planner --model wiki-gemma-12b --out .dev/eval.json
python scripts/check_local_model.py --config wikiagent.yaml --out .dev/live-model.json
```

Вторая команда проверяет чат, самолечение и книгу через настоящий API wikisvc
с реальными ответами модели во временной вики. Она не меняет рабочий контент;
фикстурные правила в main принимает тестовый человек, модель создаёт предложения.

В интеграционном прогоне v2.2 чат и самолечение прошли; все главы книги были
отклонены до генерации: llama-server превысил лимит сложности грамматики.
[v2.2 live](evals/gemma-12b-live-v2.2.json) сохраняет этот результат.
После исправления адаптера в v2.3 прошли чат, самолечение и книга:
два кандидата из трёх глав, дубликат действующего async-правила пропущен,
все цитаты и предложение валидны. Запретных вызовов нет: [v2.3 live](evals/gemma-12b-live-v2.3.json).
Это проверка API, валидации и изоляции; она не заменяет оценку качества плана.
Например, в чате Gemma объединила требования FastAPI и async в один тезис.
